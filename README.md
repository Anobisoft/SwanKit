**SwanKit** is a lightweight cross-platform utility toolkit for Swift. It provides a declarative DSL for quick UI setup, streamlined permissions management, and convenience wrappers around Apple device hardware components.

## 📱 Supported Platforms

* **Language**: Swift 6.2+ with full Strict Concurrency isolation
* **Platforms**: iOS 16.0+ | macOS 13.0+ | tvOS 16.0+ | watchOS 10.0+

## 🛠 Installation

### Swift Package Manager (SPM)
Add the following dependency directly to your `Package.swift`:

```swift
dependencies: [
    .package(url: "https://github.com/Anobisoft/SwanKit", .upToNextMinor(from: "0.1.0"))
]
```
