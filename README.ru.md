**SwanKit** — это утилитарный кроссплатформенный фреймворк для Swift, предоставляющий декларативный DSL для настройки UI, управления системными разрешениями и взаимодействия с аппаратными компонентами устройств Apple.

## 📱 Поддерживаемые платформы

* **Язык**: Swift 6.2+ с полной изоляцией Strict Concurrency
* **Платформы**: iOS 16.0+ | macOS 13.0+ | tvOS 16.0+ | watchOS 10.0+

## 🛠 Установка

### Swift Package Manager (SPM)
Добавьте зависимость в ваш `Package.swift`:

```swift
dependencies: [
    .package(url: "[HTTPS_PROTOCOL]//github.com/Anobisoft/SwanKit", from: "1.0.0")
]
```
